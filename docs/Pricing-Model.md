## Generation Rules

- 1 session = 4 photos generated
- Pessimistic deduction: deduct 4 from quota BEFORE generation starts
- Refund 4 if ALL 4 photos fail (complete failure only)
- Reset date: 1st of every month at 00:00 WIB (UTC+7)
- Unused quota does NOT carry over to next month

## Payment Flow (Phase 1 — Manual)

1. User clicks CTA on landing page
2. User fills registration form
3. User transfers to DANA Personal QRIS
4. User uploads payment screenshot
5. Admin verifies within 24 business hours
6. Admin activates account via WhatsApp + email notification
7. User receives login credentials
