# Launch-Strategy.md — PotretAI v3
*Strategi Launch Founding Member · Go-to-Market · Fase Transisi*

---

## 1. Overview Strategi

```
FASE 1 — Founding Member Launch (Hari 1 – Hari 60)
  Goal   : Jual 100 slot, generate Rp 35–45 juta
  Cara   : Urgency nyata (slot terbatas), harga eksklusif
  Target : Pasangan Indonesia yang persiapan wedding/prewedding

FASE 2 — Annual Access (Hari 61+)
  Goal   : Recurring revenue Rp 20–50 juta/bulan
  Cara   : SEO, konten, referral dari founding member
  Target : Fotografer, content creator, pasangan baru
```

---

## 2. Target Persona

### Persona 1 — "Pasangan Hemat" (Volume terbesar)
```
Usia     : 22–30 tahun
Situasi  : Persiapan menikah, budget ketat
Pain     : Studio foto mahal, fotografer susah dijadwalkan
Trigger  : "Mau foto prewedding tapi budget pas-pasan"
Platform : Instagram, TikTok, Pinterest
Paket    : Founding Premium (mau semua akses)
```

### Persona 2 — "Fotografer Profesional"
```
Usia     : 25–40 tahun
Situasi  : Bisnis fotografi, butuh preview konsep ke klien
Pain     : Tidak bisa tunjukkan konsep sebelum hari H
Trigger  : "Bisa preview dulu hasilnya sebelum bayar DP studio"
Platform : Instagram, komunitas fotografi Facebook
Paket    : Founding Premium (butuh semua kategori)
```

### Persona 3 — "Content Creator"
```
Usia     : 20–28 tahun
Situasi  : Butuh foto profesional untuk konten tapi tidak mau ke studio
Pain     : Mahal dan ribet
Trigger  : "Foto studio tanpa ke studio"
Platform : TikTok, Instagram Reels
Paket    : Founding Base atau Premium
```

## 8. Metrik yang Harus Dipantau

### Fase 1 — Founding Member

| Metrik | Target | Cara Ukur |
|--------|--------|-----------|
| Slot terjual | 100 dalam 60 hari | Database counter |
| Revenue total | Rp 35–45 juta | Total payment verified |
| Rasio Base vs Premium | 20:80 (lebih banyak Premium) | DB query |
| Waktu verifikasi rata-rata | < 4 jam | verified_at - submitted_at |
| Bukti ditolak | < 5% | Rejected / total submissions |
| Konversi landing → bayar | > 3% | Pageviews vs submissions |

### Fase 2 — Annual (Mulai Bulan 3)

| Metrik | Target | Cara Ukur |
|--------|--------|-----------|
| User baru/bulan | 30–80 | New activations |
| Revenue bulanan | Rp 20–50 juta | Monthly payments |
| Renewal rate (tahun 2) | > 40% | Renewals / expired |
| Churn rate | < 15%/bulan | Expired non-renewed / active |
| Generate usage rate | 50–80% limit terpakai | Avg used/limit |

## 9. Transisi Fase 1 → Fase 2

### Trigger Otomatis
```
IF founding_slots_sold >= 100 OR days_since_launch >= 60:

  1. Set flag di config: phase = 'annual'

  2. Update halaman pricing:
     - Sembunyikan blok Founding Member
     - Tampilkan blok Annual Pricing
     - Update semua CTA di landing page

  3. Kirim email ke semua user waitlist yang belum bayar:
     "Founding Member sudah habis. Harga naik ke annual."

  4. Update topbar app:
     - User founding: tampilkan badge "Founding Member"
     - User baru: tampilkan pilihan annual saja
```
