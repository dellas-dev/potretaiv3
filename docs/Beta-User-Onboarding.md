# Beta User Onboarding

## Tujuan

Panduan singkat untuk memasukkan 10-20 user pertama ke beta PotretAI v3.

## Langkah Admin

1. Minta user login atau register lebih dulu.
2. Minta user buka halaman `Pengaturan Akun`.
3. Minta user copy `User ID` dari account card.
4. Tambahkan `user_id` itu ke `BETA_ALLOWLIST` di worker.
5. Jika perlu, aktifkan paket awal user:
   - Spark
   - Signature
   - Prestige
6. Minta user refresh app dan test generate.

## Pesan yang Bisa Dikirim ke User Beta

Halo, akun beta Anda sudah siap.

Silakan:
- login ke PotretAI
- buka menu `Pengaturan Akun`
- copy `User ID`
- kirim User ID itu ke admin agar kami masukkan ke beta allowlist

Setelah diaktifkan, Anda bisa mulai test:
- Studio Foto AI
- Wisuda AI
- Beauty Retouch (jika paket mendukung)

## Checklist Setelah User Masuk Beta

- User bisa login
- User ID terbaca
- Beta allowlist aktif
- Paket aktif sesuai rencana
- Generate 2 foto berhasil
- Upload wajah berhasil
- Credit balance sesuai

## Catatan Operasional

- Untuk tester awal, prioritaskan `Signature`
- Gunakan `Spark` hanya untuk melihat friction upsell
- Gunakan `Prestige` untuk 1-2 tester premium saja
